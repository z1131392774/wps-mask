# 「语言」下拉什么都没生成，只把映射空间劈成了两半

*[English](2026-11-24-drop-text-language-toggle.md)*

## 问题

文本卡片上有一个「语言」下拉（中文前缀 / 英文前缀），挨着后缀位数。用户直接问它是干什么的，怀疑没用。结论比没用更糟。

`lang` 从来没进过任何生成器。`genText` 拼的是 `prefix + padNum(随机数, digits)`，`genMixed` 也走同一个辅助函数，没有任何地方读 `lang`。它唯一的作用出现在 `sigOf()` 里：

```
text|zh|姓名|2   对   text|en|姓名|2
```

两个签名，前缀相同、位数相同、生成结果同一种形态。所以翻一下下拉，就等于在**同一片可用假值上另开一个桶**，而签名本来就是用来区分“这是不是同一套映射”的。

后果有两条，都是静默的。同一个原始值出现在两张工作表上，会拿到两个不同的假值，假名不再是稳定的代号。更糟的是两个桶的前缀和位宽一样，抽取空间完全重叠：实测一个桶放七个姓名、另一个桶放七个账号，出现了 姓名4 同时对应 乙 和 E、姓名7 同时对应 丙 和 F。`buildIndex` 合并多个桶时是“先到的赢”，不做冲突检测，于是对 Sheet1 反映射，原始「甲 乙 丙 丁 戊 己 庚」被还原成「甲 E F 丁 戊 C B」——没有任何报错。

这个下拉还从来不改变用户看得见的东西：翻它，示例值那行纹丝不动，因为示例也走 `genText`。

`enPrefixOf()` 和它那张二十行的 `EN_DICT`（姓名→Name、地址→Address……）是这个想法的唯一落点，而发布代码里没有任何调用，两者只活在导出列表里。

## 决定

删掉下拉，并把 `lang` 从配置里整个拿掉。

- `sigOf` 变成 `text|前缀|位数`，只保留真正决定输出的两项。
- `defaultCfg`、`applyMask` 里混合列的文本回退、`sample`、`defaultForMode` 都不再写 `lang: 'zh'`。
- `enPrefixOf` 与 `EN_DICT` 删除，导出项一并去掉。
- 卡片改成「前缀」「后缀」两行，各自占满一行；前缀本来就是自由输入框，“填英文名”这件事它已经能做。

旧桶在加载时由 `migrateVault` 改写键名：`text|zh|姓名|2` 变成 `text|姓名|2`，桶里的记录跟着搬过去。表格一个格都不动——不重新生成假值、不重写已脱敏的单元格，所以旧版本脱敏过的文档，数据与反映射能力都保留。

这一步是靠实测定下来的，不是靠原则。不做的话，改动前映射过的文档里，同一个人在新区域再次出现时，40 次里有 34 次拿到第二个假值；而两个桶前缀、位宽都相同，40 次里有 33 次撞值。`buildIndex` 合并桶时先到的赢，撞值就意味着还原错人：表里写着 姓名3，映射表里却有两个不同的原始值同时指向它，反映射只能挑一个。改写之后，跨两个区域“映射再还原”跑了四十轮，每一格都正确回到原值。

两条护栏保证合并是干净的。目标桶已有同名键，或这个假值在目标桶里已被占用，就不搬、直接丢掉这一条——丢一条只是少一个映射，而给同一个假值造出第二个主人，就毁掉了整个工具赖以成立的 1 对 1。另一个护栏是只在中间那段是两位语言码时才改写，因此迁移是幂等的：迁移后的 `text|姓名|2` 那一段是前缀而不是 `zh`，不会再被匹配。映射表版本升到 2，加载时返回 `migrated: {moved, dropped}` 统计，测试对它有断言。

## 考虑过的其他方案

**保留下拉并让它真正生效。** 否掉了：那得在生成前把 姓名 映射成 Name，而这件事前缀框一次输入就完成了。它还会让每次切换都改变签名，身份错乱的问题依然在。

**`lang` 留在配置里，但不进 `sigOf`。** 否掉了：那就留下一个没人读、也不参与哈希的字段，专门坑下一个读代码的人，而且正是这次要拆掉的那种形状。

**把旧桶当成孤儿留着。** 实测之后否掉了：单看反映射确实没事，因为 `buildIndex` 是跨桶按假值查的，跳过判定也回退到同一份索引。但旧文档里的新区域会在同一片假值上另起一个桶——40 次里 34 次同一个人换了假值，33 次撞值。

**新签名查不到时，悄悄复用旧的 `text|zh|…` 桶。** 否掉了：每次映射都要按表头扫一遍旧桶，而且等于发明一条签名机制本身就为避开而存在的兜底规则。加载时改一次键名只做一遍，也不留这条规则。

## 后果

回归测试（第 [22] 节）钉住形状：`sigOf({mode:'text',prefix:'姓名',digits:2})` 必须等于 `text|姓名|2`；带 `lang` 残留的配置必须落进同一个桶；两种语言取样都必须是「姓名 + 两位数字」。第 [23] 节造一个带旧桶 `text|zh|姓名|1` 的文档，断言加载后合并、记录保留、旧区域仍能还原、新区域沿用旧假值而不是另生成一个、只剩一个文本桶、撞值的那条被丢弃而不是变成二对一。

`AGENTS.md` 里关于占位检查要走 `keyOf()` 的那条教训，在这里反过来也成立：凡是进 `sigOf` 的东西都必须改变输出。签名是一套映射的身份，一个只改签名的字段，就是一个会静默给所有人改名的开关。
