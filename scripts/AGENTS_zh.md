# AGENTS.md —— 门禁脚本

*[English](AGENTS.md)*

本目录下这些脚本的规矩：它们守住文档的不变式。

- **不依赖任何包的 Node ESM。** 门禁在全新检出的仓库里就能跑，不用先安装。给门禁添一个依赖，就等于在最需要它的时候用不上它。
- **预算归 `doc-budgets.json` 管。** 清单说了算，脚本只兜底它没列到的文件。上限不许在别的文件里重复。
- **带上位置失败，退出码非零。** 报 `path:line`，每一条发现都打出来，然后 exit 1。只警告却放行的门禁，教所有人学会无视它。
- **空语料算失败。** 什么都没检查的检查，什么都放行。
- **没见过的输入当敌情处理。** 清单格式错、文件读不了、链接跑出仓库，任何一样都让门禁停下；它不许降级成残缺的检查。
- **证明检查拦得住。** 提交门禁改动之前，先制造一个它本该抓住的缺陷，看它失败，再回滚。失败路径从未走过的门禁，不可信。
- **压进一秒以内。** 跑得慢的门禁，大家渐渐不在本地跑；正是本地这一跑，给了它价值。
