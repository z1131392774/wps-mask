# AGENTS.md —— 文档检查脚本

*[English](AGENTS.md)*

本目录脚本的规则：它们负责检查文档的不变式。

- **不依赖任何包的 Node ESM。** 检查脚本在全新检出的仓库里就能运行，不用先安装。给脚本添加依赖，等于让它在最需要的时候不可用。
- **预算归 `doc-budgets.json` 管。** 清单是最终依据，脚本只负责它没列到的文件的默认值。上限不许在别的文件里重复。
- **带上位置失败，退出码非零。** 报 `path:line`，打印每一条发现，然后 exit 1。只警告却放行的检查，会被所有人无视。
- **空语料算失败。** 什么都没检查的检查，什么都放行。
- **没见过的输入按不可信处理。** 清单格式错误、文件无法读取、链接指向仓库之外，任何一种都让检查停止；不许降级成不完整的检查。
- **证明检查拦得住。** 提交脚本改动之前，先制造一个它本该发现的缺陷，确认它失败，再回滚。失败路径从未执行过的检查，不可信。
- **在一秒以内完成。** 运行太慢的检查会逐渐没人在本地运行，而本地运行正是它的价值所在。
