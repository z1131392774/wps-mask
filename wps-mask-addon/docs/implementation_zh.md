# 引擎实现细节

*[English](implementation.md)*

[AGENTS_zh.md](../AGENTS_zh.md) 里各条规则背后的约定。改生成、分类或映射表格式之前先读这里；规则文件只留一行规则，理由和坑在这里。

## 一对一映射

映射表按 `n:` / `s:` / `b:`（数字、字符串、布尔）键入。生成器要探测 `used[keyOf(候选假值)]`，不是 `used[原值]`，否则撞键时会反映射回别人的原值。另有一份宽松索引，让被宿主强转过的旧假值仍可匹配；`used` 同时登记 `keyOf` 与 `looseOf` 两种形态。

数值区间刚好只放得下这些不同值时，把整列随机置换（`sattolo()`，一个环、无不动点）；逐个生成会把最后一个逼回它自己的值，固定偏移等于把原列旋转。`assignExact` 先算跨度再物化：上限 1,000,000 个值，`min`/`max` 非有限数直接拒绝，跨度太大无法置换时退回普通随机分配；区间放不下就报错，并报出列字母与表头。

## 混合列

每个值按 JS 类型分类，不看内容。数字换成数字列区间内的值；文本走 `genText`，在字段名前缀后补数字，并保证含非数字字符。反映射时 `writeColumnParts` 给每个字符串加前导单引号（宿主的文本标记），`008081` 写进常规格式也不会丢前导零，格式不变。混合列分批脱敏时若已记录假值占满数字槽位，会先自动上扩 `num.max`；写入失败的回滚也复用 `textForWrite`。反映射仍以原值为键。

## 映射表格式

`M1:`、`sigOf()` 和 `KEY_TEXT` 会被已存在的文档读取；改一个，旧桶就匹配不上。要么同一改动里加版本字段和迁移，要么在记录里说明为什么留成孤儿无妨。`sigOf()` 里每个字段都必须改变输出；只改签名不改输出的字段会悄悄把所有人改名，`lang` 就这样同时把值空间也拆了。退役的 `phone` 签名是只读兼容：区域记录里的旧签名仍能选中旧桶、旧假值精确还原，但不再生成、不迁移，版本仍是 2，旧 `phone` 设置按文本读取（[决策记录](../../.agents/notes/implemented/2026-11-27-retire-phone-and-simple-header_zh.md)）。

记住的 `min`/`max` 是数据不是策略：与当前批数据取并集、只增不减，再 `absorbBucket()`。区域仍引用的桶要保留；记录的签名找不到桶时绝不回退到全局索引，那些格子计入歧义。只因为区域引用而保留的桶，在下次保存时由 `pruneUnusedBuckets()` 删除（已无引用）。

保存是「先校验备份、再一次写入」：旧密文先备份到 B 列并读回，新密文写入 A 列后读回比对；失败则回滚或保留备份。映射、区域记录、设置记忆和边框记录都在这一次保存里落盘；`prepareMask` 先画边框，保存失败时 `abortMask` 恢复到映射前。`checkWritten()` 会重读这批写入（按宽松类型容忍宿主格式化），宿主静默吞掉写入时整批失败。回滚本身失败时，除 base 区域记录外，只为没恢复成功的列各留一条 `partial` 记录：逐行计划假值、对应原值桶键与列签名；反映射逐格比对计划假值，绝不按桶反查。

## 标记边框

`outlineAreas(vault)` 先把每列的行区间取并集（重叠与相邻记录合并，忽略签名），再把行并集相同的相邻列合并成可绘制矩形。`readEdge()` 在线型、粗细或颜色任一缺失时返回 `null`：混合边是未知样式，既不画也不猜。`clearMarkedEdge()` 只清仍是标记样式的格子，边一部分混合时按半段递归，超过 4,096 块就放弃并报错。颜色是打包整数 `15547004`（R124 G58 B237，#7C3AED）；十六进制字面量交给宿主会字节序颠倒，真机上实测偏红。`clearEdge()` 依次写颜色、粗细、线型，因为赋粗细可能把线型顶回实线。`refreshSheetMarks()` 先恢复已记录样式，再只画已知的边，画到一半失败时回滚；本次过滤范围为空时按整表刷新。

## 面板与功能区渲染

回退布局避开 flex `gap` 与 CSS 变量：内嵌浏览器版本未知，这些会静默失效。grid 只在 `@supports (display: grid)` 块里做增强，旧引擎整块忽略。面板只显示类型、示例和参数；计数归状态栏，每种状态一句话。图标是 `assets/icons/` 里的 SVG，由 `tools/make-icons.mjs` 生成 PNG；只有 `getImage` 能显示，`image=` 会被忽略。用 `node tools/preview-pane.mjs` 在 260/300/380 px 截图。
