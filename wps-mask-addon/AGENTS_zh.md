# AGENTS.md —— wps-mask-addon

*[English](AGENTS.md)*

加载项自身的规则。常驻规则在[根文件](../AGENTS_zh.md)，产品手册在 [README_zh.md](README_zh.md)。

- **取宿主对象只走 `MaskGetApp()`。** 加载项里没有裸的 `Range("A1")`：所有对象都挂在它返回的应用对象上。
- **判数组用 `Array.isArray`。** 宿主传回的值跨了上下文，`instanceof Array` 会返回 false，二维区域会静默塌成单个单元格。`analyze` 就踩过这一次。
- **整块搬运走 `Value2`。** 整块读成二维数组、在 JS 里改完、一次赋值写回。逐格循环慢一个数量级，失败时还会留下写了一半的状态。
- **映射必须一对一 —— 且必须走 `keyOf()` —— 否则抛错。** 两个原值映射到同一个值，反映射就有歧义。映射表按 `n:`/`s:`/`b:` 分键，所以用 `used[原值]` 去查重的生成器根本看不见撞车；`genPhone`/`genText` 就是这么写的，十六次里有一次还原出了错的原值。查重一律 `used[keyOf(候选)]`。区间刚好装得下这批不同值时，改成整列错位换算，不要逐个生成：最后一个会被逼到它自己的值上，于是随机失败。真装不下就报错，用字母加字段名指认是哪一列。
- **混合列按格判形态。** `shapeOf()` 给出 手机号/邮箱/固话/纯数字/字母数字/文本，`genMixed` 派给保形的生成器，认不出的回落到 `genText`。加一种形态要同时加 `shapeOf` 分支、生成器，以及一条断言"什么必须留住"的测试：域名、区号、位数、前导零。
- **映射表是文件格式。** `M1:` 信封、`sigOf()`、`KEY_TEXT` 都在被已流出的文档读取。动其中任何一处，旧表就成了垃圾：同一次改动里加上版本字段和迁移路径。
- **`engine.js` 不依赖宿主。** 不碰 DOM、不碰 `window`、顶层不用 `require`：它得在任务窗格、加载项宿主页和 Node 测试里原样跑起来。`aes.js` 不用 `crypto`。
- **改行为就要跑测试。** 引擎靠 `node test/engine.test.js` 与 `node test/aes.test.js`；用户点得到的东西还要过 jsdom 面板测试。
- **AES 密钥是混淆常量，不是凭据。** `KEY_TEXT` 就是个常量。要把它换成口令或环境变量，必须同时改存储格式。
- **改这里，别改 `%APPDATA%` 下面。** `tools/link-addon.ps1` 把装好的 `jsaddons\wpsmask_1.0.0` 变成指向本目录的目录联接。`-Rollback` 把当时存下的 `.bak-<时间戳>` 文件夹还原。
- **界面改动要在真实渲染里看。** `node tools/preview-pane.mjs` 会用十列的假工作簿生成预览页；按 260、300、380 px 三个窗格宽度各截一张图。jsdom 测试证的是行为，不是版式。窗格里别用 flex 的 `gap`、CSS 变量和 grid：内嵌浏览器版本未知，这些是静默失效，不是报错。只显示面板必须给的——类型、一个示例、参数；计数属于 WPS 状态栏，「本列 N 个不同值」那行因为重复，已经删了。
